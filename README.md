# Manual del conductor SEVIA

Guía interactiva y manual en PDF para conductores de SEVIA.

- Sitio: https://jlhdelrio-tech.github.io/sevia-manual/
- Versión del manual: 1.0, corresponde a la app de conductores v10.
- Contenido: `index.html` (guía interactiva), `manual-conductor-v1.0.pdf` (versión para imprimir), `img/` (capturas).

Este repositorio es público y solo contiene material de capacitación. No agregar datos de conductores, números de teléfono, placas reales, credenciales ni código del sistema.

Cuando cambie el chat del conductor, actualizar este manual y subir la nueva versión.
